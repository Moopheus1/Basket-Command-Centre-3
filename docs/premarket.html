Streamed by TradingView, so it updates by itself. The index futures (OANDA CFDs) trade around the clock and are the live pre-market read on the market. For stocks, TradingView's free feed is delayed (the small orange D) and only moves in the 9:30am–4:00pm ET session, so before the open its stock rows still show the previous session. The pre-market price of each stock is in the table below (from Yahoo, refreshed by the snapshot job) and as the orange Pre tag on each chart.

Table — default order is A to Z; click a column to sort, click a ticker to jump to its chart

Each average cell shows the average in dollars, then how many dollars the price is above (green) or below (red) it. Gap is price minus the last regular close. The Gap column sorts by percentage so different-priced stocks compare fairly; the sort for each average is also by percentage.

Charts — daily candles, in the same order as the table

Pre-market prices come from Yahoo Finance 1-minute bars (4:00–9:30am ET), refreshed about every 5 minutes in that window (GitHub scheduling can run late); Yahoo gives no pre-market volume, and thinly traded names can print odd prices, so treat a single pre-market tick with caution. The averages are computed from the completed daily bars in data.json (EMA9 is exponential; SMA20/50/100/200 are simple), so they do not move with the pre-market price. TradingView charts are TradingView's own embedded widget on daily candles (their data and their orange Pre tag). The free widget cannot colour moving-average lines individually, so the averages are not drawn on those charts; their values are listed under each chart and in the table. Pick “my SVG” in the chart-type box for charts with all five averages drawn in separate colours. Nothing on this page feeds TAKE, Weekly Picks, any panel or the forward log.
